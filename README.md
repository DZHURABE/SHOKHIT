# SHOKH IT — телефондан ишга тушириш (GitHub + Firebase)

Натижада сизда шулар бўлади:
- 📱 **SHOKH_IT.apk** — Android учун. Мижоз файлни босади ва ўрнатади, Chrome керак эмас.
- 🌐 **Сайт манзили** — iPhone учун: Safari'да очиб, «Бош экранга қўшиш» қилинади.
- 🔐 Ҳар бир мижоз **телефон рақами ва пароли** билан киради. Исталган телефонда маълумотлари жойида бўлади.
- 🔄 APK бир марта тарқатилади. Ҳар бир янгилик **ҳамма мижозга ўзидан** етиб боради.

Ҳаммаси бепул. Керак бўладиганлар: **Gmail**, **GitHub ҳисоби** ва телефон.

> Маслаҳат: сайтлар телефонда қулайроқ бўлиши учун Chrome менюсидан (⋮) **«Версия для ПК»** (Desktop site) бандини ёқинг.

## 1-қисм. Firebase — логин ва база
1. **console.firebase.google.com** сайтига Gmail билан киринг, **Create a project** тугмасини босинг. Номига `shokh-it` деб ёзинг. Analytics'ни ўчириб қўйиш мумкин. **Create** тугмасини босинг.
2. **Build → Authentication → Get started** бўлимига киринг. **Sign-in method** қисмида **Email/Password**ни танланг, **Enable** қилиб, **Save** тугмасини босинг.
3. **Build → Firestore Database → Create database** бўлимига киринг. Жойлашув учун `europe-west` мос келади. **Production mode**ни танлаб, **Create** тугмасини босинг.
4. Firestore'нинг **Rules** бўлимини очинг. Ундаги ҳамма матнни ўчиринг ва ўрнига **`firestore.rules`** файлининг ичидагини кўчириб қўйинг. **Publish** тугмасини босинг.
5. ⚙️ **Project settings** бўлимига киринг. Пастда **Your apps** қисмида **`</>`** белгисини босинг. Номига `SHOKH_IT` деб ёзинг ва **Register app** тугмасини босинг. Экранда `apiKey`, `authDomain` ва бошқа қийматлар чиқади, уларни ёзиб олинг. Улар 2-қисмнинг 4-қадамида керак.

## 2-қисм. GitHub — сайт ва APK
1. **github.com** сайтида рўйхатдан ўтинг. Фойдаланувчи номини (username) эслаб қолинг, масалан `shokhit`.
2. **+ → New repository** бўлимига киринг. Номига `shokh-it` деб ёзинг, **Public**ни танланг ва **Create repository** тугмасини босинг.
3. **uploading an existing file** ҳаволасини босинг. Архивдаги қуйидаги файлларни танлаб юкланг:
   `index.html`, `config.js`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `favicon.png`, `apple-touch-icon.png`, `logo.svg`, `og.png`, `robots.txt`.
   Кейин **Commit changes** тугмасини босинг.
4. Рўйхатдан **`config.js`** файлини очинг ва ✏️ (Edit) тугмасини босинг. `PASTE_...` деб ёзилган жойлар ўрнига 1-қисмнинг 5-қадамида олган қийматларингизни ёзинг. **Commit changes** тугмасини босинг.
5. **Settings → Pages** бўлимига киринг. **Source** қисмида **GitHub Actions**ни танланг.
6. **Add file → Create new file** бўлимига киринг. Файл номига айнан шуни ёзинг:
   `.github/workflows/build.yml`
   Ичига архивдаги **`build.yml`** файлининг ҳамма матнини кўчириб қўйинг. **Commit changes** тугмасини босинг.
7. **Actions** бўлимини очинг. GitHub иловани ўзи тўплайди, бу 5–10 дақиқа олади. Иккала қатор ёнида ✅ белгиси пайдо бўлса, тайёр.

   ❌ белгиси чиқса, қаторни очиб **Re-run jobs** тугмасини босинг. Бу ҳам ёрдам бермаса, экраннинг расмини менга юборинг.

## 3-қисм. Охирги созлаш
1. Firebase'да **Authentication → Settings → Authorized domains → Add domain** бўлимига киринг. У ерга `USERNAME.github.io` деб ёзинг, `USERNAME` ўрнига ўзингизнинг GitHub номингизни қўйинг.

   Бу қадамни қилмасангиз, кириш ишламайди.
2. **APK'ни биринчи марта тўплаш:** **Actions → SHOKH_IT → Run workflow** бўлимига киринг, **build_apk**ни белгиланг ва **Run**ни босинг. 5–10 дақиқа кутинг.
3. Энди сизда иккита нарса бор:
   - **Сайт:** `https://USERNAME.github.io/shokh-it/`
   - **APK:** GitHub'даги репозиторийнинг **Releases** бўлимида, **SHOKH_IT.apk** файли.

## Мижозларга тарқатиш
- **Android:** Releases бўлимидаги **SHOKH_IT.apk** ҳаволасини ёки файлнинг ўзини WhatsApp орқали юборасиз. Мижоз файлни босиб, **«Ўрнатиш»**ни танлайди. Биринчи марта «Рухсат бериш»ни ҳам босиши керак.
- **iPhone:** сайт манзилини юборасиз. Мижоз уни Safari'да очади, «Улашиш» (□↑) тугмасини босиб, **«Бош экранга қўшиш»**ни танлайди.
- Мижоз иловани очиб, **«Рўйхатдан ўтиш»**ни босади, рақами ва паролини ёзади. Тамом.

## Янгилик киритсангиз (APK қайта юборилмайди)
APK'ни мижозларга **бир марта** тарқатасиз, бошқа ҳеч қачон юбормайсиз.

1. GitHub'да **Add file → Upload files** орқали янги `index.html` файлини юклаб, **Commit changes** тугмасини босасиз.
2. 2–3 дақиқадан кейин сайт янгиланади (**Actions** бўлимида ✅ белгиси чиқади).
3. Мижоз иловани очганда ёки унга қайтганда илова янги версияни **ўзи юклайди**. Ҳеч нарса босиш шарт эмас.

Агар мижоз шу пайт қарз ёзаётган бўлса, илова кутиб туради ва ёзиб бўлгандан кейин янгиланади. Маълумотлар ўчмайди, улар Firebase'да сақланади.

**APK қачон керак бўлади?** Биринчи марта ва фақат иконкани ёки илова номини ўзгартирсангиз. Бунинг учун **Actions → SHOKH_IT → Run workflow** бўлимига киринг, **build_apk**ни белгиланг ва **Run**ни босинг. APK **Releases** бўлимида пайдо бўлади.

Рўйхатдан ўтиш мумкин бўлган мамлакатлар: Тожикистон, Ўзбекистон, Россия, Қозоғистон, Қирғизистон, БАА, Корея, АҚШ ва «Бошқа» (исталган код).

- Мижоз рўйхатдан ўтгандан кейин **30 кун бепул** ишлатади. Бош экранда «Бепул: N кун қолди» деган ёзув туради.
- Муддат тугаса, илова ёпилади ва **«WhatsApp'га ёзиш»** тугмаси чиқади. Бу тугма сизнинг рақамингизга (+992 93 991 11 99) тайёр хабарни мижоз рақами билан юборади.
- Мижознинг маълумотлари **ўчмайди**. Тўлов қилгандан кейин ҳаммаси жойида бўлади.

**Тўловни илова ичида қабул қилиш:**
1. Карталарингиз (Хумо, Душанбе Сити, Алиф) иловага олдиндан ёзилган. Бошқа мамлакатлар учун алоҳида реквизит ёзмоқчи бўлсангиз, **Админ панел → Реквизитлар** бўлимига ҳар бир мамлакат учун пулни қаерга юбориш кераклигини ёзинг (карта рақами, Click, Payme, Сбербанк ва ҳоказо) ва **Сақлаш**ни босинг.
2. Мижоз тўлов экранида ўз мамлакатининг реквизитларини кўради, пулни ўтказади ва **«✓ Мен тўладим»**ни босиб, изоҳ ёзади.
3. **Админ панел → Тўловлар** бўлимида янги сўров пайдо бўлади (қизил рақам билан). Пул келганини текширинг ва **«✓ Тасдиқлаш»**ни босинг. Мижознинг доступи танлаган тарифи бўйича ўзидан очилади.

**Доступни қўлда бериш:**
1. Иловага **ўзингизнинг рақамингиз** (939911199) билан рўйхатдан ўтинг. Шу рақам админ ҳисобланади ва унинг учун муддат тугамайди.
2. **Профил → Админ панел** бўлимига киринг. У ерда барча мижозлар ва уларнинг ҳолати кўринади: Бепул, Тўланган ёки Тугаган.
3. Мижоз пулни тўлагандан кейин унинг қаторидаги мижоз тўлаган тарифни (**1 ой / 3 ой / 6 ой / 1 йил**) босинг. Мижоз ўз иловасида **«Текшириш»**ни босса, илова дарҳол очилади.
4. **«Ўчириш»** тугмаси мижознинг доступини дарҳол тўхтатади.

Админ рақамини ўзгартирмоқчи бўлсангиз, иккита жойни ўзгартиринг: `index.html` ичидаги `ADMIN_PHONE` қатори ва `firestore.rules` ичидаги `992939911199` рақами. Рақам мамлакат коди билан бирга ёзилади.

**Муҳим:** `firestore.rules` файлини ўзгартирсангиз, унинг янги матнини Firebase'нинг **Firestore → Rules** бўлимига қайта қўйиб, **Publish** тугмасини босинг. Бу 1-қисмнинг 4-қадами.

## Мижоз паролни унутса
Буни Firebase'га кирмасдан, ўз телефонингиздан қиласиз:
1. **Профил → Админ панел** бўлимига киринг ва мижозни топинг.
2. **«🔑 Парол»** тугмасини босинг, кейин тасдиқлаш учун яна бир марта босинг.
3. Шу заҳоти мижознинг эски пароли ишламай қолади. Экранда **«Мижозга хабар юбориш»** тугмаси чиқади: у мижозга WhatsApp орқали тайёр йўриқнома юборади.
4. Мижоз иловани очади, **ўша рақам** билан **«Рўйхатдан ўтиш»**ни босади ва янги парол қўяди.
5. Мижознинг ҳамма маълумоти ва тўлаган муддати **жойида қолади**.

Паролларни ҳеч ким кўра олмайди, сиз ҳам. Шу сабабли унутилган паролни кўрсатиб бўлмайди, фақат янгисини қўйиш мумкин.

Эслатма: 🔑 тугмасини фақат ростдан ҳам ўша рақам эгаси ўз рақамидан ёзганига ишонч ҳосил қилгандан кейин босинг.

## Янги одамлар учун
- **Тур:** иловани биринчи марта очганда 4 та экранда илова қандай ишлашини кўрсатади.
- **«🧪 Намуна билан синаб кўринг»:** бўш иловада 3 та намуна мижоз қўшади. «Тозалаш» тугмаси уларни ўчиради.
- **«📇 Контактлардан»:** Android'да мижозни телефон китобидан қўшиш мумкин.
- **«🎁 Дўстингизни таклиф қилинг»** (Профилда): мижоз ўз ҳаволасини юборади. Дўсти рўйхатдан ўтиб, биринчи тўловини сиз тасдиқлаганингизда, **иккаласига ҳам +15 кун** ўзидан қўшилади. Админ панелда ким кимни таклиф қилгани кўринади.
- **«⏰ Тўлов муддати»:** бош экранда муддати келган ёки ўтган қарздорлар чиқади. Ҳар бирига битта тугма билан WhatsApp'да эслатма юборилади.
- **«📄 Ҳисобот»:** мижоз саҳифасида туради. Мижознинг барча олган ва тўлаган пуллари рўйхати WhatsApp ёки Telegram'га юборилади.

## Дўкон учун қўшимча имкониятлар
- **📦 Товарлар ва нархлар** (Профил → Товарлар): товар, нарх ва бирлигини бир марта ёзиб қўясиз. Қарз ёзаётганда товарни боссангиз, сумма ва изоҳ ўзи тўлади, масалан «Ун × 2, Шакар × 1».
- **🚦 Қарз лимити**: мижозни таҳрирлашда лимит қўйилади. Қарзи лимитдан ошса, қарз ёзаётганда огоҳлантириш чиқади ва рўйхатда «Лимитдан ошган» белгиси туради.
- **📅 Бўлиб тўлаш (насия)**: қарз ёзаётганда «Бўлиб тўлаш»ни белгилаб, ойлар сонини ва биринчи тўлов санасини танлайсиз. Илова ойлик жадвал тузади, тўловларни ўзи ҳисоблайди ва муддат келганда эслатади.
- **⚫ Қора рўйхат**: мижоз саҳифасидаги ⚫ тугмаси билан белгиланади. Мижозни очганда огоҳлантириш чиқади.
- **📊 Кунлик ҳисобот** (Тарих бўлимида): бугун қанча қарз берилгани, қанча пул олингани, янги мижозлар ва муддати ўтганлар сони. Ҳисоботни WhatsApp ёки Telegram'га юбориш мумкин.

Бош экрандаги **«📊 Ҳисоб-китоб»** тугмаси (у «Тарих» бўлимида ҳам бор) ҳамма мижозни битта жадвалда кўрсатади: **Олди · Берди · Қолди**.
- Даврни танлаш мумкин: бугун, шу ҳафта, шу ой ёки бутун вақт.
- Тепада жами суммалар туради.
- Жадвални қолган қарз, олинган товар ёки исм бўйича саралаш мумкин. Фақат қарздорларни кўрсатадиган фильтр ҳам бор.
- Мижоз қаторини боссангиз, унинг саҳифаси очилади.
- Бутун жадвални битта тугма билан WhatsApp'га юбориш мумкин.

## 🚚 Доставщиклар
Бу дўконга товар олиб келадиганлар учун алоҳида рўйхат. Уни бош экрандаги **«🚚 Доставщиклар»** тугмаси ёки **Профил → Доставщиклар** орқали очасиз.
- **+ Янги доставщик** тугмаси билан исми, телефони ва нима олиб келишини ёзасиз, масалан «Алишер · ун, шакар».
- **📦 Товар олдим** — доставщик товар олиб келганда босилади, масалан «10 қоп ун — 2 000». Шунда сизнинг унга қарзингиз ошади.
- **💸 Пул бердим** — унга пул тўлаганингизда босилади, масалан «800». Бу пул хазинадан ҳам ўзидан айирилади, лекин хоҳласангиз буни ўчириб қўйишингиз мумкин.
- Ҳар бир доставщикда **Менинг қарзим 1 200 с.** каби ёзув, жами олинган товар ва жами тўлов, ҳамда барча ёзувлар тарихи кўринади.
- Бош экранда **«🚚 Доставщиклар 1 200»** ёзуви доставщикларга жами қанча қарз эканингизни кўрсатиб туради.
- **WhatsApp** тугмаси доставщикка тайёр ҳисоб-китоб хабарини юборади.
